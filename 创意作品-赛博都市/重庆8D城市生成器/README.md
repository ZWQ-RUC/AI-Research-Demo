# 山城造物 · 重庆 8D 魔幻城市生成器 (`CHONGQING · 8D CITY FORGE`)

对标 [OpenAI Official Showcase - Procedural City Generator](https://developers.openai.com/showcase/procedural-city-generator) 与 Bilibili [Claude Fable 5.2 首发实测《山城造物》](https://www.bilibili.com/opus/1269065529242419207) 打造的纯前端程序化 3D 重庆魔幻城市生成引擎。

## 1. 系统架构与数据流图

```
+-----------------------------------------------------------------------------------+
|                        UI Control Panel (山城图谱 8 大参数维度)                     |
|  [城市布局] [功能配比] [天际线] [城市风格] [山城地形] [立体交通] [光照氛围] [视角机位] |
+-----------------------------------------+-----------------------------------------+
                                          | 实时状态驱动 (appState)
                                          v
+-----------------------------------------------------------------------------------+
|                     ChongqingCityGenerator (程序化几何与拓扑引擎)                   |
|  1. SeededRandom + 2D Simplex/FBM Noise -> 渝中半岛脊线 / 南山 / 江北嘴台地高程场   |
|  2. 两江交汇水体场 (长江浑黄 + 嘉陵江碧绿 -> 朝天门“鸳鸯锅” Sigmoid 混合边界)       |
|  3. 重庆地标建模: 朝天门来福士(四帆列阵+水晶连廊+斜拉冠) / 洪崖洞11层吊脚楼 / 解放碑 |
|  4. 8D 立体交通: 李子坝&牛角沱真实几何镂空穿楼门洞 + 单轨高架 + 5层黄桷湾/盘龙立交  |
|  5. 跨江斜拉桥群 (东水门/千厮门/嘉华/菜园坝) + 长江索道悬索 + 1,100+ 山地吊脚塔楼   |
+-------------------+-------------------------------+-------------------------------+
                    | 静态几何合并缓冲               | 拓扑路网与轨道样条
                    v                               v
+-----------------------------------+   +-------------------------------------------+
|   ChongqingWebGLRenderer (GLSL)   |   |  HUD 遥测 & 2D 拓扑雷达小地图 & 防重叠标注 |
|  - Sky & 3D Horizon Mountain Pass |   |  - 左下角实时小地图 (两江/路网/立交/视锥) |
|  - Procedural Window Facade Pass  |   |  - 3D->2D 屏幕投影 + AABB 碰撞斥力防重叠  |
|  - Dynamic Trains/Cableway/Traffic|   |  - 顶部胶囊统计栏 & 底部构建耗时/FPS 监控  |
+-----------------------------------+   +-------------------------------------------+
```

## 2. 快速运行方式

1. **零依赖直接运行**：双击或用浏览器直接打开 `index.html` 即可流畅运行完整 3D 城市生成器。
2. **运行 15 组参数自动化冒烟测试**：
   ```bash
   node scripts/smoke_test.js
   ```
