## 二、作品 I · 瑶琳仙境 (Yaolin Wonderland 3D)

> *“跟着一只大黄狗，钻进亿万年的溶洞深处。”*

### 1. 艺术构思与沉浸叙事
项目以浙江桐庐闻名天下的“瑶琳仙境”喀斯特溶洞为蓝本。不同于常规冰冷的数字展厅，本项目引入了一只灵动活泼的纯代码解剖级**中华田园犬——“大黄”**作为探索伙伴：
- 立耳、额段起伏、湿润黑鼻镜、琥珀杏仁眼；
- 奔跑时镰刀尾随风摆动，四蹄踏雪，步态自然轻盈；
- 停步静候时，会自主转动头部、耸嗅鼻尖，东闻西探，带来极富生命温度的陪伴感。

### 2. 关键核心技术架构
- **零依赖自研 WebGL 场景图引擎** (`js/engine.js`)：支持多光源喀斯特岩溶漫反射、水面微波法线扰动、丁达尔体积光柱（Tyndall Beams）与空气湿润水汽微粒系统。
- **程序化骨架与动态骨骼动画** (`js/dog.js`)：完全由数学几何放样构建的犬体解剖结构，内建行走、小跑、嗅闻、原地待命的平滑过渡有限状态机（FSM）。
- **自然分形地形算法** (`js/noise.js` + `js/cave.js`)：利用 3D Perlin / FBM 噪声场塑造嶙峋怪石、钟乳石笋林与曲折地道。
- **实时音频生成引擎** (`js/audio.js`)：采用 Web Audio API 振荡器与白噪声滤波器，实时程序化合成空灵钟乳水滴声、幽深暗河回声与沙石脚步声，无需加载音频素材。

### 3. 探索路线与地质景观
1. **前厅 · 江南水乡**：小桥流水、暗河浅滩，温婉清澈的初入洞境。
2. **第一洞厅 · 仙女聚会**：宽广磅礴，气象万千，神似仙袂飘举的巨大钟乳群。
3. **第二洞厅 · 龙宫峡谷**：幽深冷峻、暗流汹涌，悬崖与飞瀑呼应。
4. **第三洞厅 · 三十三重天**：高逾十丈的擎天玉柱拔地而起，千百石笋如万树争荣。

## 三、作品 II · 山城造物 (Chongqing 8D City Forge)

> *“轻轨穿楼过，两江分色流；千楼叠嶂起，九重立交错。”*

### 1. 赛博母体与山城拓扑
对标国际前沿的程序化城市生成（Procedural City Generation）理念，以高密度、大高差的中国“赛博第一城”重庆为灵感源泉。利用拓扑算法重塑“屋顶即是马路，一楼连着悬崖”的八维魔幻空间。

### 2. 关键核心技术架构
- **程序化山水高程场**：通过 SeededRandom 种子结合 2D Simplex/FBM 噪声，实时计算渝中半岛脊线、南山山体、江北嘴台地，生成富于侵蚀感的陡峭地貌。
- **两江交汇流体模拟**：长寿长江（浑黄沉郁）与温润嘉陵江（碧绿清亮）在朝天门相遇，通过 Sigmoid 平滑过渡曲线呈现著名的“鸳鸯火锅”水体分界。
- **标志性建筑与立体交通群**：
  - **来福士广场**：曲面弯弧四帆列阵、空中水晶连廊与斜拉幕墙；
  - **洪崖洞民俗风貌区**：多层退台挑梁、仿古飞檐吊脚楼群；
  - **李子坝穿楼单轨**：真实的 3D 几何镂空穿楼门洞与动态巡航列车；
  - **垂直交通体系**：多层盘旋立交桥、跨江斜拉大桥（千厮门/东水门）、长江索道缆车及 1,100+ 栋随坡度自适应生长的山地建筑群。
- **极致渲染性能优化**：海量建筑几何体动态 Batching 合并，着色器程序化实时生成夜间点阵窗格光斑，保持 60 FPS 丝滑帧率。

### 3. 八维图谱参数体系
系统提供交互式「山城图谱」控制台，开放 8 大可调维度：
`[城市布局]` · `[功能配比]` · `[天际线形态]` · `[城市风格]` · `[山城地形]` · `[立体交通]` · `[光照与天候]` · `[观察者机位]`。

## 四、快速上手与本地启航 (Quick Start)

仓库内所有项目均以现代 Web 标准编写，**免打包、免重型依赖安装**，开箱即刻启动。

### 1. 本地一键启动静态服务（推荐）
在仓库根目录下，你可以使用附带的自动化脚本或随附的标准运行时启动预览：

```bash
# 方式 A：利用 Python 自带轻量服务器启动
python3 -m http.server 8080

# 方式 B：如果你使用 Windows，可直接双击运行
start_server.bat
```
浏览器访问：
- **瑶琳仙境**：`http://localhost:8080/创意作品-琳琅仙境/瑶琳仙境/index.html`
- **山城造物**：`http://localhost:8080/创意作品-赛博都市/重庆8D城市生成器/index.html`

### 2. 单文件独立离线运行
如果你需要将作品单体分发或在无网络环境展示：
- 直接在文件管理器中双击 `创意作品-琳琅仙境/瑶琳仙境/yaolin_wonderland_singlefile.html` 即可独立运行！
- `创意作品-赛博都市/重庆8D城市生成器/index.html` 采用高内聚架构，同样支持直接在现代浏览器中本地开启体验。

## 五、技术理念与核心特色 (Design Philosophy)

1. **零外部重型资产 (Zero External Assets)**
   告别动辄数百兆的 FBX/GLTF 网格模型与纹理贴图。所有的岩石裂理、水流涟漪、毛发质感、摩天大楼窗户，全部源于数学公式、分形几何与像素级着色器。
2. **纯粹的数学秩序美学 (The Aesthetics of Math)**
   从 `Catmull-Rom` 样条曲线引导的漫游轨迹，到 Simplex 噪声雕刻的起伏山峦，再到确定性随机数（PRNG）控制下的千变万化，每一个场景都蕴含着算法的精密与优雅。
3. **跨端自适应与多维交互 (Responsive & Immersive)**
   完备支持桌面端鼠标键盘（WASD + 视角俯仰）以及移动端多点触控与虚拟操作摇杆。集成 HUD 遥测、实时游线雷达小地图与地质名胜气泡导览。
