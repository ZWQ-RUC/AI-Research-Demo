# 瑶琳仙境 3D 溶洞探秘 (Yaolin Wonderland 3D Cave Exploration)

本项目采用 **纯代码程序化 3D 建模与自定义 WebGL 着色器** 从零构建浙江桐庐 **瑶琳仙境** 喀斯特溶洞与 **3D 仿真中华田园犬（大黄）**，不使用任何外部 `.glb/.obj` 3D 模型或贴图文件，支持桌面端与移动端响应式交互。

## 目录结构

- `index.html`：模块化入口页面（可直接通过本地静态服务器或浏览器打开）
- `yaolin_wonderland_singlefile.html`：单文件内联独立运行版（双击即可运行）
- `css/style.css`：响应式多端 UI 样式（开场封面、洞厅标题、解说卡片、实时游线小地图、移动端虚拟摇杆）
- `js/noise.js`：确定性随机数、三维分形噪声 (`fbm3D`) 与三维样条曲线 (`CatmullRomSpline3D`)
- `js/engine.js`：零依赖 WebGL2/WebGL1 场景图与多光源喀斯特岩溶/水面波纹/丁达尔体积光柱/水汽粒子/皮毛着色器引擎
- `js/spots.js`：瑶琳仙境四大洞厅（前厅·江南水乡、第一洞厅·仙女聚会、第二洞厅·龙宫峡谷、第三洞厅·三十三重天）及 18 处真实景观数据
- `js/dog.js`：纯代码解剖级放样建模的中华田园犬“大黄”（立耳、额段、湿润黑鼻镜、杏仁眼、下颌舌头、深胸收腰、四蹄浅白、镰刀卷尾，含自然行走/小跑与停下东闻西嗅状态机）
- `js/cave.js`：瑶琳仙境洞体、银河飞瀑（7米高×13米宽）、擎天玉柱（14米高）、三十三重天层叠石笋林、瑶琳玉峰、地下暗河与洞内彩灯生成器
- `js/audio.js`：基于 Web Audio API 的实时合成溶洞环境音（空灵水滴声、地下暗河流水声、大黄脚步声）
- `js/main.js`：交互控制、第三人称跟随相机、“大黄带路”自动巡游与 2D 游线图实时绘制
